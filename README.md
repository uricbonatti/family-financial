# Family Financial

App desktop (Electron + React + TypeScript) de planejamento financeiro familiar: renda fixa e pontual, despesas
(pontuais, recorrentes, parceladas e planejadas), saldo projetado de 12 meses, plano de redução e contribuição
recorrente pelo calendário Badí’. Dados 100% locais em SQLite, valores em centavos inteiros, regras de domínio puras e testadas.

- `code/`: aplicação (veja [code/README.md](code/README.md) para rodar, testar e gerar o instalador)
- `docs/`: requisitos e diagramas (casos de uso, modelo de dados, arquitetura, estados)
- `prototype/`: protótipo de interface e projeção de referência

Os nomes, rendas e despesas dos dados de exemplo são fictícios.
